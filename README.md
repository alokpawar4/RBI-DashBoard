# RBI Economic Dashboard – Power BI

## Project Overview
The RBI Economic Dashboard is an interactive data visualization project developed using Microsoft Power BI. It provides insights into India's economic indicators through interactive visuals, KPI cards, charts, and year/month filters.

## Dashboard Preview
![RBI Economic Dashboard](Dashboard.png)

## Key Performance Indicators (KPIs)
- Foreign Exchange Reserves (USD Billion)
- Repo Rate (Current Policy Rate)
- Currency in Circulation
- Bank Credit
- Deposit Mobilisation
- Inflation (Consumer Price Index – CPI)
- UPI Growth (Year-over-Year)

## Dashboard Features
- Interactive Year and Month slicers.
- Foreign Exchange Reserves KPI with monthly comparison.
- Repo Rate analysis and historical trend.
- Bank Credit vs Bank Deposits comparison.
- Currency in Circulation analysis.
- Deposit Mobilisation analysis.
- Inflation (CPI) monitoring.
- UPI Growth (YoY) visualization.
- Conditional formatting for positive and negative growth.

## Tools & Technologies
- Microsoft Power BI

- Data Cleaning and Transformation
- Data Modelling

## Project Objectives
1. Analyze important Indian economic indicators.
2. Monitor changes in monetary policy rates.
3. Compare bank credit and deposit trends.
4. Track inflation and UPI growth.
5. Present economic data through an interactive dashboard.

## How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Refresh the data if the source files are available.
4. Use Year and Month slicers to explore the dashboard.
